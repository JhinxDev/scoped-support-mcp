# Working on the example

Use Node.js 24 or newer. Run npm ci --ignore-scripts, npm run check, npm test and npm run demo before proposing a change.

Keep fixtures fictional, tool scope narrow and examples runnable. When changing a boundary, add a test that demonstrates the attempted bypass or failure. Update README and SECURITY.md when behavior changes. Do not add secrets, production customer data or generated node_modules to commits.

This repository is not open-source licensed. Please open a sanitized issue to discuss a proposed change before submitting code.
